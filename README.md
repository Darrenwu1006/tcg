# BreakTCG

BreakTCG is a personal Haikyuu!! Vobaca!! BREAK simulator for deck testing, match-flow practice, and future AI opponent experiments.

## Run Locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run build
```

## Notes

- Manual play and AI battle experiments live in the app source.
- Card data lives under `public/`.
- Local planning, handoff notes, and work logs live under `docs/`, which is intentionally kept private and ignored by git.
