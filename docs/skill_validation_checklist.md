# 关键卡片验证清单

## 验证目标

验证 15 张最常用/最复杂的卡片，确保技能解析正确无误

## 验证标准

### ✅ 必须检查的项目

1. **效果类型正确**：stat_boost / draw / discard / search / special
2. **目标正确**：self / opponent
3. **数值正确**：与原文一致
4. **条件完整**：所有触发条件都记录
5. **选择者明确**：谁选择效果（player/opponent/random）

### ⚠️ 常见错误

- stat 字段错误（serve vs attack vs toss etc）
- 缺少 selector 字段（谁选择）
- 缺少多重效果（只保留了第一个效果）
- 条件不完整

## 待验证卡片列表（15 张）

### 🔴 高优先级（核心卡片）

#### 1. 及川 徹 (HV-P01-033) - 頂卡

**原文**：從自己的手牌將 1 枚<青葉城西>的卡片棄掉則可使用。這名角色的任意 1 個點數+1，若對手的手牌在 4 枚以上，對手從手牌棄掉 1 張卡。

**当前 JSON**：

```json
{
  "effects": [
    {
      "type": "stat_boost",
      "target": "self",
      "stat": "any",
      "value": 1
    },
    {
      "type": "discard",
      "target": "opponent",
      "value": 1,
      "condition": "對手手牌>=4"
    }
  ]
}
```

**需要检查**：

- [ ] stat: "any" - ✅ 正确（任意点数）
- [ ] 第二个效果缺少 selector: "opponent"（对手自己选择丢哪张）
- [ ] 缺少 visibility: "hidden"（暗丢）

#### 2. 日向 翔陽 (HV-P01-002) - 頂卡

**原文**：支付 3 Guts 即可使用。此角色的攻擊點數+4，在下一個對手的回合中，對手不能讓基礎接球點數 6 以上的接球角色登場。

**需要检查**：

- [ ] 攻击点数+4
- [ ] 限制对手接球角色（这是特殊效果，需要 type: "special"）

---

#### 3. 影山 飛雄 (HV-P01-006) - 頂卡

**原文**：支付 2 Guts 即可使用。公開自己牌組最上方的 1 張卡，可將其中 1 張「日向 翔陽」或「開放式進攻」加入手牌，未加入的卡片放到牌組最下方。此外，此回合中，自己的「日向 翔陽」每登場 1 次，該角色的攻擊點數+2。

**需要检查**：

- [ ] type: "search" - 检索牌顶
- [ ] selector: "player" - 玩家选择是否加入手牌
- [ ] 第二个效果：连锁效果（每次登场+2）

---

#### 4. 孤爪 研磨 (HV-P01-018) - 頂卡

**原文**：支付 3 點毅力(Guts)即可使用。此角色的托球點數+1，若自己所有角色皆為音駒，可從自己的事件區域將最多 1 張卡片加入手牌。

**需要检查**：

- [ ] 托球点数+1
- [ ] 条件效果（所有角色为音駒）
- [ ] type: "search" - 从事件区检索
- [ ] optional: true（"最多"表示可选）

#### 5. 黑尾 鐵朗 (HV-P01-021) - 頂卡

**需要检查**：

- [ ] 攻击点数+3

**原文**：當自己的發球角色或托球角色是「及川 徹」時可以使用。抽 1 張卡，並將自己 1 名「及川 徹」角色的托球點數+1。此外，在下一個對手的回合中，對手每次以「抽卡」以外的方式將卡片加入手牌時，對手必須從手牌棄掉 1 張卡。

**需要检查**：

- [ ] 触发条件（及川徹在场）
- [ ] 抽卡效果
- [ ] 托球+1
- [ ] 持续效果（下回合限制）

## 验证流程

### Step 1: 自动检查

运行验证脚本，自动标记可疑项

### Step 2: 人工核对

逐一对照原文，确认 JSON 正确性

### Step 3: 记录问题

发现的所有问题记录到 `skill_issues.json`

### Step 4: 修正

应用修正，更新 JSON

### Step 5: 标记

验证通过的卡片标记 `"verified": true`
